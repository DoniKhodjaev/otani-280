# Отани 280

PWA с ежедневным планом по таблице Отани: задачи на день по дню недели, отметки, серия дней и пуш-уведомление в 6:30 (Ташкент).

- `index.html`, `sw.js`, `manifest.webmanifest`: приложение (GitHub Pages)
- `tasks.json`: расписание задач и сроки. Правится прямо на GitHub, приложение и уведомления берут задачи отсюда
- `supabase/functions/otani-push`: функция Supabase, которая хранит подписки и отправляет пуш по таймеру (pg_cron, 01:30 UTC)

## Установка на iPhone

1. Открой сайт в Safari
2. «Поделиться» → «На экран „Домой“»
3. Открой приложение с домашнего экрана и нажми «Включить уведомления»
